# NetSim

Editor-only multi-client sync test for VRChat worlds: several clients run as copies of your world scene in one Unity
Editor, connected through a simulated network with latency, jitter and loss.

Open *Tools > NetSim > NetSim Window*. Manual: [Documentation~/README.md](Documentation~/README.md)
(日本語: [Documentation~/README.ja.md](Documentation~/README.ja.md)). Repository:
https://github.com/haselab-net/vrchat-netsim
